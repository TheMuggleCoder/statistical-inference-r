## Discussion of Results

#The results show the effect of n and lambda on the MLE of the exp distribution. For all 3 lambda values (0.5, 1, 2), the bias and mse decreases as n increases. The estimator becomes more accurate and approaches towards unbiasness as n increases.This shows the practical example of CLT.
#Lambda is directly proportional to Bias and MSE is proportional to Lambda^2.As efficiency does not depends on lambda , it was found identical for all 3 parameter values and approaches to 1 as n increases and becomes asymptotically efficient.
#Sometimes very small differences occur in simulated results and analytical results due to random sampling variation and finite number of replications (1000).Overall increasing n, improves the performance of MLE, while changing lambda affects its bias and MSE but not its efficiency.

#Comment on the distribution of the sample m
#The distribution of the sample mean depends on the underlying population distribution and sample size.
#Exponential Distribution (lambda = 1):
#for n = 5 the distribution is right skewed and does not look like a normal distribution. however as the sample size increases 20 and then 50 , the distribution becomes more symmetric and approximately normal . This show the Central Limit Theorem that as the n gets bigger, the distribution tends towards normal distribution.
#Bernoulli Distribution  (p = 0.50):
#for n = 5, the plot is symmetric. However unlike normal data, the bernoulli data is discrete. for n = 5, the sample means can only take 6 distict values - 0 , 0.2, 0.4, 0.6, 0.8, 1. Due to the same reason the Q-Q plot shows horizontal bands.  As the sample size increases to 20 and 50, the distribution becomes more bell shaped and resembles normal distribution and the Q-Q plot show improved alignment with the reference line. 
#Bernoulli Distribution (p = 0.05):
#The sample distribution remains right skewed for smaller sample sizes. Even at n = 50, it is right skewed. This is because the probability of success is small (p = 0.05), which results in relatively few successes with each sample.
#Overall the result show that the CLT describes the convergence of sampling distribution towards normal distribution as the value of n increases (n being sample size). However the rate of convergence depends on the population distribution. Skewed distributions and distributions with low probability of success may require comparatively larger n value (sample size) for a reasonable normal approximation.

plot_wilks <-  function(x, sample_size){
  n <-  length(x)
  mle <- n / (n *log(12) - sum(log(x)))
  max_ll <- log_likelihood(mle, x)
  cutoff <-  max_ll - d/2
  #find lower and upper confidence limits
  lower <- uniroot(
    function(theta) log_likelihood(theta, x) - cutoff,
    interval = c(0.000001, mle)
  )$root
  
  upper <- uniroot(
    function(theta) log_likelihood(theta, x) - cutoff,
    interval = c(mle, 5)
  )$root
  
  theta_values <- seq(0.001, 5, length.out = 1000)
  
  ll_values <- sapply(theta_values, log_likelihood, x = x)
  
  plot_data <- data.frame(
    theta = theta_values,
    loglik = ll_values
  )
  
  print(
    ggplot(plot_data, aes(x = theta, y = loglik)) +
      geom_line() +
      geom_hline(yintercept = cutoff,
                 color = "red", linetype = "dashed") +
      geom_vline(xintercept = lower,
                 color = "blue", linetype = "dashed") +
      geom_vline(xintercept = upper,
                 color = "blue", linetype = "dashed") +
      geom_vline(xintercept = mle,
                 color = "darkgreen", linetype = "dotted") +
      labs(
        title = paste("Wilks Confidence Interval (n =", sample_size, ")"),
        x = "Theta",
        y = "Log-Likelihood"
      ) +
      theme_minimal()
  )
  cat("Sample size:", sample_size, "\n")
  cat("MLE:", mle, "\n")
  cat("Lower limit:", lower, "\n")
  cat("Upper limit:", upper, "\n\n")
  
}
plot_wilks(x10, 10)

plot_wilks(x100, 100)

plot_wilks(x1000, 1000)

set.seed(48703186)
theta <- 1
xmax <- 12
negative_log_likelihood <- function(theta, x) {
  if(theta <= 0) return(1e100)
  -log_likelihood(theta, x)
}
one_simulation <- function(n) {
  x <- xmax * runif(n)^(1/theta)
  result <- nlm(negative_log_likelihood, p=1, x=x, hessian=TRUE)
  mle <- result$estimate
  se <- sqrt(1/as.numeric(result$hessian))
  lower <- mle - 1.96 * se
  upper <- mle + 1.96 * se
  mom <- mean(x)/(xmax-mean(x))
  coverage <- (lower <= theta && theta <= upper)
  return(c(MLE=mle, MoM=mom,
           Lower=lower, Upper=upper,
           Coverage=coverage))
}
n <- c(10, 100, 1000)
results <- list()
for(j in 1:length(n)) {
  simulations <- replicate(1000, one_simulation(n[j]))
  results[[j]] <- as.data.frame(t(simulations))
}
summary_results <- data.frame(
  Sample_Size = n,
  Mean_MLE = sapply(results, function(x) mean(x$MLE)),
  Mean_MoM = sapply(results, function(x) mean(x$MoM)),
  MLE_Bias = sapply(results, function(x) mean(x$MLE) - theta),
  MoM_Bias = sapply(results, function(x) mean(x$MoM) - theta),
  Wald_Coverage = sapply(results, function(x) mean(x$Coverage))
)
summary_results

The bias of both estimators decreases considerably, indicating improved estimation accuracy with larger samples. In these simulations, the MoM estimator has slightly lower bias than the MLE at all three sample sizes.

Overall, the results are consistent with expectations: both estimators become more accurate with increasing sample size, while the Wald confidence intervals maintain coverage close to their nominal level.

  lambda_lower <- lambda_hat - 1.96*se_lambda

  se_median <- median_hat/sqrt(n)
  median_lower <- median_hat - 1.96*se_median
  median_upper <- median_hat + 1.96*se_median
  lambda_cover[i] <- (lambda_lower <= lambda &&
                        lambda <= lambda_upper)
  median_cover[i] <- (median_lower <= true_median &&
                        true_median <= median_upper)
