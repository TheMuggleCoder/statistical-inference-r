# Statistical Inference using R

R programming and statistical simulations for Statistical Inference.

## Overview

This repository contains R implementations and statistical simulations completed as part of the MSc Data Science and Statistical Learning course at the University of Limerick. The work explore statistical estimation, sampling distributions, and fundamental statistical concepts using R.

## Topics Covered

### Question 1: Maximum Likelihood Estimation (MLE)
- Exponential distribution
- Maximum Likelihood Estimation of λ
- Bias and Variance
- Cramér-Rao Lower Bound (CRLB)
- Estimator Efficiency
- Mean Squared Error (MSE)
- Simulation and comparison of analytical and empirical results

### Question 2: Central Limit Theorem (CLT)
- Sampling distributions of sample means
- Normal distribution
- Exponential distribution
- Bernoulli distribution
- Histograms and Normal Q-Q plots
- Effect of sample size on normal approximation

## Technologies Used

- R
- ggplot2

## How to Run

1. Clone this repository.
2. Open the R scripts in RStudio.
3. Install the required packages.
4. Run the scripts to reproduce the simulations and visualisations.
